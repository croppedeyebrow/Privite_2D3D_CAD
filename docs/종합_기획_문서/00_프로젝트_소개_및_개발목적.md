## 1. 제품 정체성

**CAD Studio 2.0은 Windows 오프라인 환경에서 2D 기계/건축 도면을 정밀 작성하고, 구속 2D 스케치를 이용해 3D 파라메트릭 기계 부품을 모델링하며, CAD 뷰포트와 제품 프레젠테이션 렌더링을 제공하는 단일 사용자 엔지니어링 도구**입니다.

원래의 강점은 유지합니다: (1) 로컬 우선 (2) 반복 제작/출력 자동화 (3) 명령 이력 및 복구 (4) 추적 가능한 치수·공차 (5) GUI·CLI 공유 엔진. 확장되는 축은 (6) 설계 의도 보존 (7) 정밀 B-Rep 솔리드 (8) 3D 표면·모서리 선택 및 수정 (9) STEP 등 교환 (10) GPU 렌더링입니다.

## 2. 대상 문제·사용자

- **기계 설계/제작:** 브래킷·하우징·플레이트·축·간단한 치구/고정부품; 치수 수정→피처 재생성→제작 전달용 STEP/STL.
- **2D 도면:** 부품도, 치수·공차·레이어·용지 스케일·레이아웃; 인쇄와 재생성의 일관성.
- **개인 도면 외주/제작:** 유사한 부품군을 파라미터 변경하여 반복 제작, 검증 및 일괄 출력.
- **건축:** 2D 평면도와 표준 기하/치수부터 시작; 3D 벽·슬래브·개구부·층, BIM/IFC 호환은 별도 후속 제품 라인.

### 제품 경계

- **P0 / R0~R2:** 범용 2D 작성 + 정밀 3D *단일 파트* 모델링(파라메트릭 피처 일부), CAD 뷰포트, 핵심 파일 입출력, 저장/복구.
- **P1 / R3:** 필렛·챔퍼·패턴, 2D 투상도 및 인쇄 레이아웃, PBR 미리보기/고해상도 스틸 이미지, 파라메트릭 템플릿/일괄 처리.
- **P2 / R4+:** 어셈블리, 구속 조립, 3D 주석(GD&T/PMI), 판금, CAM, 간섭검사, 건축 객체/IFC.
- **제외:** 실시간 멀티유저, 클라우드 의존 서비스, 완전 DWG 호환, 산업용 인증 CAE/CAM, 대형 플랜트 BIM, 포토리얼 오프라인 패스 트레이싱을 초기 성공 조건으로 삼지 않음.

## 3. 제품 원칙

1. **원본 데이터와 표현 분리:** CAD 문서의 도메인 데이터가 진실의 원천. 테셀레이션·BVH·GPU 버퍼는 파생 캐시.
2. **2D/3D 연계:** 2D Drafting 엔티티와 평면 내 2D Sketch 엔티티를 개념상 구분하고, Sketch는 3D Feature 입력이 될 수 있음.
3. **안정 ID와 안정 참조 구분:** Document/Feature/Sketch ID는 안정적으로 보존; B-Rep 생성 후 edge/face는 복구 가능한 참조 전략이 필요함(완전 보장 불가).
4. **모든 쓰기 = Command Transaction:** 명령 실행·검증·커밋 또는 전체 롤백; Undo/Redo·이력 갱신·저장은 일관성 보장.
5. **실패는 문서 손상으로 이어지지 않아야 함:** 계산 실패·GPU 실패·외부 파일 오류의 격리, 마지막 성공 상태 유지.
6. **계산 모델 기준 단위 mm, 좌표 f64:** 파일 교환 시 단위를 명시적으로 변환. 허용오차는 연산·규모별 정책으로 구성.
7. **버전/호환성 우선:** native format·커널/피처 버전·마이그레이션·복구를 명시.
8. **수치 결과의 과장 금지:** 동일 입력의 결정적 결과는 동일 버전·동일 환경·규칙과 정규화 조건 아래에서 검증; 크로스 플랫폼 비트 단위 동일성을 약속하지 않음.

## 4. 단계별 출시 정의

| 버전 | 사용자가 완료할 수 있는 일 | 운영상 출시 기준 |
|---|---|---|
| R0 기술 기반 | 저장/복구 가능한 문서, 2D line/circle, CLI 검증 | 소스·테스트·CLI 완료 |
| R1 usable 2D | 스냅/치수/레이어/Undo 포함 2D 도면 SVG/DXF(별도 검증) | 표준 도면 10개 편집·출력 재확인 |
| R2 **usable 3D part** | 구속 스케치→Extrude/Revolve/Cut→STEP/STL→파일 재편집 | 기준 부품 5종 완주 + 독립 CAD 교차검증 |
| R3 제작·시각화 | Fillet/Chamfer/Pattern(게이트 통과 기능), 모델 링크 2D 뷰, PBR 이미지 | 실패 시 안전한 기능 저하 + 회귀시험 |
| R4 이후 | Assemblies/건축 객체/PMI | 별도 범위 승인 후 진입 |

## 실사용 범위(R2 사용자 수용 정의)

1. 사용자가 새 문서에서 **100 × 60 × 10 mm** 판재 파트를 설계합니다.
2. 평면 스케치를 만들고 중심 원을 구속하여 관통 홀을 생성합니다.
3. Extrude 및 Boolean Cut을 실행하고 Body 유효성을 검사합니다.
4. 치수 값을 변경하여 영향 피처를 의존성 순서대로 재계산합니다.
5. GPU 뷰포트에서 면·모서리 선택이 정확히 작동합니다.
6. 프로젝트를 저장하고 재시작하여 설계 파라미터·피처 이력을 복구합니다.
7. STEP으로 내보내 외부 CAD에서 확인하고 형상 편차를 비교합니다.
8. CLI validate/export 및 손상 복구를 같은 애플리케이션 서비스로 실행합니다.

**R2에 포함되지 않는 기본 가정:** 고급 어셈블리 구속, 포토리얼리즘 렌더링, IFC/BIM, 완전한 DWG 호환, 클라우드 협업. 로드맵만 수립하고 별도 출시 게이트를 둡니다.
