## 7. Dimension / Tolerance

- `Dimension`의 참조는 원본 geometry 및 expression. 단순 text span 금지.
- 공차 모델: symmetric ±, asymmetric +/-, limit max/min; 계산 trace 및 원본 입력 목록 보존.
- 기하 값과 표시용 반올림 분리, 단위변환/소수점 유효자릿수 정책.
- **도면 표기용 공차와 파라메트릭 sketch driving dimension은 의미가 다름.** 검증 UI에 표시.
- GD&T, ISO fits, datum 및 법적/제조 표준 적합 판정은 P2 별도 전문기능 검증 범위.

## 제조용 도면 R3 단계 요구사항(추가 상세화)

- part body와 연결된 ViewDefinition(정면/평면/측면)을 Sheet의 외부 참조 객체로 보관합니다.
- 모형 형상 변경 시 drawing projection cache를 무효화하고 해당 뷰의 치수 참조를 재검증합니다.
- 표준 치수 표시, 공차, 표면거칠기, GD&T는 기술적 정확도와 규격 라이선스를 검토한 뒤 단계별 활성화합니다.
- 숨은선/가시선, 인쇄 축척, 도면 단위, 문자 폰트, 선가중치를 PDF/SVG golden 비교로 검증합니다.
