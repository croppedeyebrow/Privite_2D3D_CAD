## R1

2D 작성/검증/저장/복구/출력이 실행 가능해야 합니다.

## R2

스케치→솔리드→재계산→뷰포트→저장→STEP 실제 사용자 시나리오를 독립적으로 완주합니다.

## R3

정투상 연계·고급 피처·PBR 렌더의 데이터/출력 일관성 테스트를 통과합니다.

## R4

어셈블리/건축 의미 모델은 별도 규격·도메인 검증 후 조건부 출시합니다.
