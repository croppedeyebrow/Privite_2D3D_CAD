## 목적과 경계

AeroOps/FarmTwin과 유사한 8단계 단기 스프린트 문서 형태를 제공하되 CAD 2D/3D 전체를 20일에 완성할 수 있다는 일정 약속은 아닙니다. 이 스프린트는 **기술검증, 기존 코드 회귀 보존, 핵심 계약 도출**을 위한 실험용 계획입니다.

| 단계 | 참고 일차(가정) | 주요 범위 | 검증 결과 |
|---|---:|---|---|
| S01 | 1~2 | 레포·툴체인 인벤토리 | baseline inventory |
| S02 | 3~4 | Stable ID·unit API | type tests |
| S03 | 5~7 | OCCT/Truck/FFI 빌드 PoC | compile/report |
| S04 | 8~10 | 단일 B-Rep fixture | shape volume/bbox |
| S05 | 11~12 | Sketch Solver 후보 | DOF/problem cases |
| S06 | 13~15 | wgpu 3D view spike | orbit/pick latency |
| S07 | 16~18 | STEP & native save spike | round-trip/loss report |
| S08 | 19~20 | 통합 측정·ADR 작성 | go/no-go + residual risk |

**일차는 노력을 가늠하는 임시 분할**이며 시행 결과에 따라 조정합니다. 성능·호환성·안전성 미달이면 다음 단계 기능 개발보다 해당 위험 해결을 우선합니다.
