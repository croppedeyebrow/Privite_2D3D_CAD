## 기술 결합 지도

`사용자 도면 편집 → GUI 입력 → Domain/Command → Sketch/Feature → Kernel → Native Model → Exchange/Render/Recover` 입니다. 제품 설계 원본과 rendering mesh, GPU 버퍼의 권위가 다릅니다.

| 기술군 | 목적 | 기술 | 검증 경계 |
|---|---|---|---|
| 언어 | 앱/코어 | Rust | 타입/수명/Result |
| Native | B-Rep | OCCT C++ / Truck | ABI/shape validity |
| Math/Solver | 기하/구속 | robust predicates, solver port | 허용오차/수렴 |
| GPU | viewport/PBR | wgpu/WGSL | driver/device loss |
| Persistence | 프로젝트 | versioned format | power-loss/recovery |
| Exchange | 제조 협업 | STEP/STL/DXF | unit/topology/loss report |
| Ops | 배포/QA | CI/SBOM/test matrix | build reproducibility |
