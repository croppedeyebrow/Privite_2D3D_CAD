## 상태·규칙

- **현재 상태는 설계 문서 정리본**입니다. 연결된 실제 소스 저장소를 분석했다는 뜻이 아닙니다.
- 제품 출시 목표(R1~R4)와 구현 작업 단계(P00~P12)는 별도 축입니다.
- OCCT/Truck, GPU backend, Sketch Solver는 평가 대상이며 기술 선정은 PoC 뒤 ADR 확정합니다.
- R2는 간단한 파라메트릭 기계 부품을 2D 스케치로 만들어 수정·저장·STEP 교환하는 사용자 완주로 정의합니다.
- 단기간(20일) 계획은 **환경 검증 및 핵심 위험 감소**만 대상으로 하며 3D CAD 완성을 보장하지 않습니다.
