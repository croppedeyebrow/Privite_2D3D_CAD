## 실사용 범위(R2 사용자 수용 정의)

1. 사용자가 새 문서에서 **100 × 60 × 10 mm** 판재 파트를 설계합니다.
2. 평면 스케치를 만들고 중심 원을 구속하여 관통 홀을 생성합니다.
3. Extrude 및 Boolean Cut을 실행하고 Body 유효성을 검사합니다.
4. 치수 값을 변경하여 영향 피처를 의존성 순서대로 재계산합니다.
5. GPU 뷰포트에서 면·모서리 선택이 정확히 작동합니다.
6. 프로젝트를 저장하고 재시작하여 설계 파라미터·피처 이력을 복구합니다.
7. STEP으로 내보내 외부 CAD에서 확인하고 형상 편차를 비교합니다.
8. CLI validate/export 및 손상 복구를 같은 애플리케이션 서비스로 실행합니다.

**R2에 포함되지 않는 기본 가정:** 고급 어셈블리 구속, 포토리얼리즘 렌더링, IFC/BIM, 완전한 DWG 호환, 클라우드 협업. 로드맵만 수립하고 별도 출시 게이트를 둡니다.

## 추가 품질 시나리오

- 여러 시간 편집한 문서를 강제 종료 후 자동 저장 후보로 복구합니다.
- 피처 구속이 깨진 문서를 저장해도 오류 위치와 영향 범위가 확인됩니다.
- 지원하지 않는 STEP 객체를 읽으면 손실·무시·읽기 전용 중 해당 상태를 명시합니다.
- 렌더링 GPU 장치가 사라져도 원본 CAD Document는 손상되지 않습니다.
