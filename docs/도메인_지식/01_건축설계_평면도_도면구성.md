## BIM 이전 단계의 건축 CAD 범위

- 평면도·입면도·단면도, 치수선·중심선·그리드, 출력축척, 도면층과 문자 스타일, 벽/문/창 표기와 공간 중심선을 학습합니다.
- 설계 프로그램의 표현은 법적 건축 기준 검토 결과가 아닙니다. 설계도면의 건축법 적합성 검증을 기능으로 주장하지 않습니다.

## 구현 순서

1. 2D Drafting: scale·unit, layer, hatch/line style, paper space.
2. 3D: wall/floor/opening semantic entities 추가(공간과 관계 분리).
3. Projection: section/elevation linked view + dynamic recompute.
4. IFC는 지원 범위/엔터티/표준 라이선스/적합성 테스트가 끝난 후 결정.

## 예시 테스트

벽 두께 변경→평면도/단면도 갱신, 도어 opening 이동→wall hole 갱신, 층 높이 변경→입면도 표시 검증.
