# UI 구성 기획

## 1. UI 목표

CAD Studio UI는 화면을 화려하게 만드는 것보다 도면을 빠르고 정확하게 작성하고 상태를 잃지 않도록 하는 것을 목표로 한다.

- 캔버스 작업을 중심으로 한다.
- 좌표, 단위, 스냅, 저장 상태를 항상 확인할 수 있게 한다.
- 속성 변경은 command로 처리한다.
- 검증 오류와 공차 결과를 숨기지 않는다.
- 긴 작업 중에도 현재 상태를 명확히 표시한다.

## 2. 기본 레이아웃

```text
┌──────────────────────────────────────────────────────────┐
│ 메뉴 바: 파일 / 편집 / 보기 / 도구 / 출력                 │
├──────────────────────────────────────────────────────────┤
│ 도구 모음: 선택 / 선 / 폴리라인 / 사각형 / 원 / 호 / 텍스트 │
├──────────────┬───────────────────────────────┬───────────┤
│ 왼쪽 패널    │                               │ 오른쪽    │
│ 도구/레이어  │          도면 캔버스            │ 속성/검증 │
│              │                               │ 치수/공차 │
├──────────────┴───────────────────────────────┴───────────┤
│ 명령 입력 | 좌표 | 단위 | 스냅 | 선택 수 | 저장 상태       │
└──────────────────────────────────────────────────────────┘
```

## 3. 영역별 구성

### 3.1 메뉴 바

- 파일: 새로 만들기, 열기, 저장, 다른 이름으로 저장, 복구, 종료
- 편집: 실행 취소, 다시 실행, 삭제, 복사, 붙여넣기
- 보기: 확대, 축소, 전체 보기, 그리드, 스냅
- 도구: 선택, 도형, 치수, 공차, 텍스트, 검증
- 출력: SVG, PDF, DXF, batch export

저장되지 않은 변경이 있을 때 새로 만들기, 열기, 종료를 실행하면 저장 여부를 확인한다.

### 3.2 도구 모음

초기 도구:

- 선택
- 선
- 폴리라인
- 사각형
- 원
- 호
- 텍스트
- 치수
- 그룹
- 그룹 해제
- 실행 취소
- 다시 실행

현재 선택된 도구는 명확한 강조 상태를 가진다.

### 3.3 왼쪽 패널

왼쪽 패널은 도구와 레이어를 제공한다.

레이어 항목:

- 레이어 이름
- 현재 작업 레이어
- 표시/숨김
- 잠금/해제
- 색상
- 선 스타일
- 객체 수

잠긴 레이어의 객체는 선택·이동·삭제할 수 없다.

### 3.4 중앙 캔버스

캔버스 기능:

- 도형 표시
- 좌표 입력
- 마우스 pan
- 휠 zoom
- grid 표시
- snap 표시
- 선택 강조
- 작성 중 미리보기
- 이동 중 미리보기
- 치수와 공차 표시

캔버스는 도메인 데이터를 직접 수정하지 않고 UI 이벤트만 생성한다.

### 3.5 오른쪽 패널

오른쪽 패널은 검증, 속성, 치수, 공차를 탭 또는 구역으로 제공한다.

속성 탭:

- Entity ID
- 종류
- 레이어
- 좌표
- 길이
- 반지름
- 각도
- 텍스트 내용

치수·공차 탭:

- nominal
- 공차 방식
- upper/lower 또는 plus/minus
- min/max
- 계산 trace
- 경고

검증 탭:

- 오류 수
- 경고 수
- 대상 객체
- 문제 설명
- 해결 제안

검증 항목을 클릭하면 대상 객체가 캔버스에서 선택되어야 한다.

### 3.6 하단 상태 영역

- 현재 명령
- 커서 좌표
- 현재 단위
- snap 상태
- 선택 객체 수
- undo/redo 가능 여부
- 저장됨/변경됨/저장 중/저장 실패

## 4. 주요 사용자 흐름

### 4.1 도형 작성

```text
도구 선택
-> 캔버스 입력
-> snap 후보 계산
-> 미리보기
-> 입력 확정
-> AddEntity command
-> 검증
-> 렌더 갱신
-> 자동 저장 예약
```

### 4.2 객체 편집

```text
객체 선택
-> 속성 패널 표시
-> 값 편집
-> SetEntityGeometry command
-> 검증
-> undo 기록
-> 캔버스 갱신
```

### 4.3 공차 편집

```text
치수 선택
-> 공차 방식 선택
-> 값 입력
-> SetTolerance command
-> 계산
-> 결과와 trace 표시
-> 경고 표시
```

### 4.4 저장

```text
저장 명령
-> 모델 검증
-> 임시 파일 저장
-> 다시 읽기 검증
-> 원자적 교체
-> 저장 상태 갱신
```

## 5. UI 상태와 도메인 상태 분리

### UI 상태

- 현재 도구
- 선택 객체
- 카메라 위치와 확대율
- 패널 열림 상태
- 포인터 위치
- 작성 중인 임시 입력
- 편집 중인 속성 draft

### 도메인 상태

- Project
- Drawing
- Entity
- Layer
- Dimension
- Tolerance
- Group

UI 상태는 영속 파일에 직접 저장하지 않는다. 영속 상태 변경은 command로만 수행한다.

## 6. 오류와 안전성 UX

- 오류는 빨간색, 경고는 노란색 계열로 구분한다.
- 오류 메시지는 대상과 해결 방법을 포함한다.
- 저장 실패 시 기존 파일을 유지한다.
- 저장되지 않은 변경은 제목과 상태 영역에 표시한다.
- 파괴적 동작은 확인 대화상자를 표시한다.
- 자동 저장 중에는 상태를 표시하되 캔버스 입력을 불필요하게 막지 않는다.

## 7. 접근성과 입력 규칙

- 모든 주요 도구에 키보드 단축키를 제공한다.
- `Ctrl+Z`, `Ctrl+Y`, `Ctrl+Shift+Z`를 지원한다.
- Escape는 현재 작성 중인 작업을 취소한다.
- Delete는 선택 객체를 삭제한다.
- 숫자 입력은 단위를 명확히 표시한다.
- 포커스 상태가 보이도록 한다.
- 한글 폰트가 없는 환경에서도 핵심 기능이 중단되지 않게 한다.

## 8. UI 완료 기준

- 새 프로젝트와 파일 열기·저장이 화면에서 가능하다.
- 도형 작성, 선택, 이동, 삭제가 동작한다.
- 속성 변경이 command와 undo/redo에 반영된다.
- 검증 오류가 대상 객체와 함께 표시된다.
- 공차 결과와 계산 trace를 확인할 수 있다.
- 저장 상태와 자동 저장 상태를 확인할 수 있다.
- 주요 기능을 마우스와 키보드로 사용할 수 있다.
