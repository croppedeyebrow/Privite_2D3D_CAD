# CAD Studio 프로젝트 기획서

문서 버전: 0.1  
작성 목적: Rust 기반 건축·기계 2D CAD 프로그램의 제품 방향과 초기 개발 범위를 정의한다.

## 1. 프로젝트 개요

CAD Studio는 건축 및 기계 설계 도면을 제작하는 개인 설계자를 위한 로컬 중심 2D CAD 프로그램이다.

이 프로젝트는 대규모 동시 접속이나 실시간 협업보다, 한 명의 사용자가 장시간 작업하면서 많은 도면을 안전하게 만들고 반복 출력할 수 있는 환경을 제공하는 데 초점을 둔다.

핵심 문장:

> 혼자서 많은 도면을 안전하고 반복 가능하게 생산하는 Rust 기반 CAD 저작 시스템

## 2. 추진 배경

건축 및 기계 설계 작업은 다음과 같은 문제를 반복적으로 가진다.

- 장시간 작업 중 파일 손상 또는 저장 실패 위험
- 유사한 도면을 반복 제작할 때 발생하는 수작업 부담
- 치수와 공차 계산 결과를 검토하기 어려움
- 출력 결과가 작업 환경이나 실행 시점에 따라 달라질 가능성
- GUI에 기능이 집중되어 자동화와 대량 출력이 어려움
- 도면 데이터와 화면 상태가 강하게 결합되어 유지보수가 어려움

CAD Studio는 이 문제를 안정적인 도메인 엔진, command 기반 변경, 자동 저장과 복구, 추적 가능한 계산 결과로 해결한다.

## 3. 제품 목표

### 3.1 핵심 목표

1. 건축 및 기계 2D 도면을 작성할 수 있는 기본 작업 환경을 제공한다.
2. 작업 중인 도면을 안전하게 저장하고 복구할 수 있게 한다.
3. 반복 작업과 대량 출력을 자동화할 수 있는 기반을 만든다.
4. 치수와 공차 계산의 입력, 과정, 결과를 확인할 수 있게 한다.
5. 동일한 입력에 대해 동일한 계산 및 출력 결과를 보장한다.
6. GUI와 CLI가 동일한 도메인 엔진을 공유하도록 설계한다.

### 3.2 성공 기준

- 사용자가 새 프로젝트를 만들고 기본 도형을 작성할 수 있다.
- 저장, 자동 저장, 백업, 복구 흐름이 동작한다.
- 기본 치수와 공차의 최소값·최대값을 계산할 수 있다.
- 계산 결과의 근거를 사용자가 확인할 수 있다.
- GUI 없이 프로젝트 검증과 출력 작업을 실행할 수 있다.
- 핵심 기능에 자동화된 테스트가 존재한다.

## 6. 주요 기능

### 6.1 프로젝트 및 파일 관리

프로젝트는 도면, 레이어, 스타일, 치수, 공차, 메타데이터를 하나의 작업 단위로 관리한다.

필수 기능:

- 새 프로젝트
- 다른 이름으로 저장
- 불러오기
- 자동 저장
- 백업 생성
- 비정상 종료 후 복구
- 저장 전 유효성 검사

파일 관련 작업은 임시 파일 작성, 검증, 원자적 교체 순서를 따른다.

### 6.2 도면 작성

사용자는 중앙 캔버스에서 도형을 작성하고 편집한다.

초기 도형:

- 선
- 폴리라인
- 사각형
- 원
- 호
- 텍스트

도형은 안정적인 ID, 레이어 ID, 스타일 참조, 기하 데이터를 가진다.

### 6.3 치수와 공차

치수 객체는 연결된 기하 객체와 표시 설정을 가진다.

초기 치수:

- 선형 치수
- 정렬 치수

초기 공차:

- 공차 없음
- 대칭 공차
- 상하 공차
- 한계 공차

공차 계산 결과는 다음 정보를 제공한다.

- 기준값
- 최소값
- 최대값
- 계산식 또는 계산 설명
- 입력 치수 목록
- 경고 사항

표시용 반올림 값과 내부 계산 값을 분리한다.

### 6.4 검증

검증 결과는 오류와 경고로 구분한다.

오류 예시:

- 중복 객체 ID
- 잘못된 기하 데이터
- 존재하지 않는 참조 객체
- 손상된 프로젝트 구조
- 유효하지 않은 출력 대상

경고 예시:

- 공차 미지정
- 기본 스타일 적용
- 사용하지 않는 레이어
- 대체 폰트 사용

### 6.5 출력과 자동화

GUI와 CLI는 동일한 도메인 엔진을 사용한다.

예상 CLI:

```text
cad validate project.cadproj
cad export project.cadproj --format svg
cad batch-export ./jobs
cad inspect project.cadproj
cad recover project.autosave.cadproj
```

## 7. 화면 구성

```text
┌─────────────────────────────────────────────────────────┐
│ 메뉴                         도구 모음                  │
├──────────────┬──────────────────────────────┬───────────┤
│ 도구/레이어  │                              │ 속성/검증 │
│              │          도면 캔버스          │           │
│              │                              │           │
├──────────────┴──────────────────────────────┴───────────┤
│ 명령 입력 / 좌표 / 스냅 상태                 저장 상태 │
└─────────────────────────────────────────────────────────┘
```

화면 영역:

- 상단 메뉴: 파일, 편집, 보기, 도구, 출력
- 도구 모음: 선택, 도형, 치수, 텍스트, 실행 취소, 다시 실행
- 왼쪽 패널: 도구와 레이어
- 중앙 캔버스: 도면 표시 및 포인터 입력
- 오른쪽 패널: 선택 객체 속성, 치수, 공차, 검증 결과
- 하단 영역: 명령 입력, 좌표, 단위, 스냅 상태, 저장 상태

UI 상태와 도메인 상태는 분리한다. 속성 패널에서 값을 바꾸는 경우에도 core model을 직접 수정하지 않고 command를 발생시킨다.

## 8. 기술 구성

### 8.1 기술 방향

- 언어: Rust
- 구조: Cargo workspace
- 실행 방식: 로컬 데스크톱 애플리케이션과 CLI
- 내부 길이 단위: 밀리미터
- 기본 안전 정책: `unsafe` 금지
- 외부 의존성: 필요성과 보안 영향을 검토한 후 추가

### 8.2 crate 구성

```text
cad_core       도메인 모델과 안정 ID
cad_geometry   기하 계산
cad_tolerance  공차 계산
cad_command    명령, 실행 취소, 다시 실행
cad_render     렌더 모델 변환
cad_io         저장, 불러오기, 출력
cad_batch      반복 작업과 대량 출력
cad_cli        명령줄 인터페이스
cad_app        GUI 애플리케이션
```

### 8.3 데이터 흐름

```text
사용자 입력
  -> UI 이벤트
  -> DrawingCommand
  -> Core Model 변경
  -> 검증
  -> Render Model 갱신
  -> 화면 표시 / 저장 / 출력
```

## 9. 안전성 정책

제품의 최우선 기준은 데이터 안전성이다.

- 모든 영속 객체에 안정 ID를 부여한다.
- 모든 도면 상태 변경은 command를 통해 수행한다.
- 저장 전 모델을 검증한다.
- 저장은 임시 파일과 원자적 교체를 사용한다.
- 자동 저장과 백업을 제공한다.
- 출력은 deterministic해야 한다.
- 파괴적 파일 작업은 사용자 승인을 요구한다.
- 저장 형식 변경은 마이그레이션과 복구 계획을 함께 제시한다.

- core model에 반영되어 있다.
- command로 실행할 수 있다.
- 저장 및 불러오기 정책이 정의되어 있다.
- 검증 규칙이 있다.

## 13. 기획 결론

CAD Studio는 많은 기능을 한 번에 제공하는 범용 CAD보다, 개인 설계자의 반복 작업을 안정적으로 처리하는 도면 제작 엔진을 우선한다.

개발의 기준은 다음 순서를 따른다.

```text
도면 데이터 안정성
-> 명령 기반 변경
-> 계산 추적성
-> 저장과 복구
-> 결정적 출력
-> 사용자 인터페이스
```
