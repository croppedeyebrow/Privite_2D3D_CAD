# CAD Studio 개발 목적 및 세부 기획

## 1. 문서 목적

이 문서는 CAD Studio의 제품 목적, 대상 사용자, 핵심 기능, 개발 범위와 우선순위를 정의한다.

## 2. 개발 목적

CAD Studio는 건축 및 기계 설계 도면을 개인 사용자가 안전하고 반복 가능하게 제작할 수 있도록 하는 로컬 중심 2D CAD 프로그램이다.

대규모 동시 접속보다 다음을 우선한다.

- 장시간 작업 안정성
- 도면 데이터 손실 방지
- 자동 저장과 복구
- 반복 도면 생산성
- 공차 계산의 추적 가능성
- 동일 입력에 대한 동일 출력
- GUI와 CLI의 엔진 재사용

## 3. 해결할 문제

- 수작업 도면 반복으로 인한 생산성 저하
- 저장 실패와 파일 손상으로 인한 데이터 손실
- 치수와 공차 계산 근거 확인의 어려움
- GUI에 종속된 작업으로 자동화가 어려움
- 내부 데이터와 외부 파일 형식이 결합되는 문제

## 4. 대상 사용자

- 개인 건축 설계자
- 기계 설계자
- 프리랜서 및 도면 외주 작업자
- 반복 도면을 많이 제작하는 사용자
- 클라우드 협업보다 로컬 보안을 우선하는 사용자

## 5. 제품 범위

### 5.1 1차 범위

- 프로젝트 생성, 저장, 불러오기
- 자동 저장, 백업, 복구
- 2D 캔버스, pan, zoom, grid
- 선, 폴리라인, 사각형, 원, 호, 텍스트
- 선택, 이동, 삭제
- 레이어와 기본 스타일
- 선형 치수와 정렬 치수
- 대칭, 상하, 한계 공차
- 공차 범위와 계산 trace
- 검증 패널
- SVG 출력
- CLI validate

### 5.2 후속 범위

- PDF, DXF 출력
- 블록과 심볼
- 템플릿
- 반복 도면과 batch export
- 끼워맞춤 표
- 공차 누적 UI
- GD&T
- 스크립트와 매크로

### 5.3 제외 범위

- 실시간 다중 사용자 협업
- 클라우드 전용 저장
- 3D 솔리드 모델링
- 완전한 DWG 호환
- 웹 기반 SaaS

## 6. 핵심 사용 시나리오

### 시나리오 A: 기본 도면 작성

1. 사용자가 새 프로젝트를 생성한다.
2. 레이어를 선택한다.
3. 캔버스에서 도형을 작성한다.
4. 스냅으로 정확한 위치를 지정한다.
5. 속성 패널에서 좌표와 형상을 조정한다.
6. command 단위로 undo/redo를 수행한다.

### 시나리오 B: 치수와 공차 검토

1. 도형에 치수를 배치한다.
2. 공차 유형을 선택한다.
3. nominal, min, max를 확인한다.
4. 계산 trace와 경고를 확인한다.
5. 검증 오류가 없을 때 출력한다.

### 시나리오 C: 안전한 저장과 복구

1. 저장 전 모델 검증을 수행한다.
2. 임시 파일에 저장한다.
3. 저장 결과를 다시 읽어 검증한다.
4. 원자적으로 본 파일을 교체한다.
5. 자동 저장과 백업을 갱신한다.
6. 비정상 종료 시 복구 파일을 별도로 연다.

## 7. 기능 우선순위

우선순위는 다음 순서를 따른다.

```text
저장과 복구
-> 핵심 도형 편집
-> 치수와 공차 UI 연결
-> 출력
-> 반복 생산 자동화
-> 외부 CAD 교환
-> 전문 3D 기능
```

## 8. 완료 기준

기능은 다음 조건을 만족해야 완료로 본다.

- 도메인 모델에 반영되어 있다.
- command로 실행된다.
- 오류와 경고가 구분된다.
- 저장 형식 영향이 정의되어 있다.
- 자동화 테스트가 있다.
- GUI 또는 CLI에서 접근할 수 있다.
- 실패 원인이 사용자에게 표시된다.
