## 현재 상태와 요구 조사

**실제 Git repository의 소스/커밋은 본 문서 생성 시 검증하지 않았습니다.** 아래 파일은 P00에 작성할 실측 분석을 위한 기준표입니다.

| 항목 | 현행 분석 | 유지/확장/교체 결정 | 대응 테스트 |
|---|---|---|---|
| `cad_core` | 미확인 | Stable ID/Document 확장 | JSON round-trip |
| `cad_geometry` | 미확인 | 2D 보존/3D 분리 | 2D fixture |
| `cad_command` | 미확인 | transaction/revision 확장 | undo/redo |
| `cad_render` | 미확인 | RenderScene 분리 | deterministic ordering |
| `cad_io` | 미확인 | native v2 migration | backward read |
| `cad_app` | 미확인 | Workbench UI 도입 | keyboard/pan/zoom |

## 전환 불변조건

기존 2D 파일을 읽을 수 있어야 하고, v1 파일 마이그레이션에 실패해도 원본은 남아야 합니다. 모든 영속 변경은 Command를 통해 이루어지며 GUI/CLI가 동일한 규칙을 사용합니다.
