## 전환 순서

1. 기존 실행과 저장/출력 샘플을 고정하고 `cad_types` 같은 하부 계약부터 추가합니다.
2. 기존 2D Entity/Layer는 Adapter를 통해 새 Document에 읽기 전용 투영합니다.
3. 새 Command path를 선택적 기능으로 도입하고 parity test 결과를 비교합니다.
4. Feature DAG/3D kernel은 별도 path에서 개발하며 기존 2D 출력 경로를 유지합니다.
5. 저장 포맷 v2를 도입할 때 v1 reader와 **명시적 저장/마이그레이션**을 분리합니다.
6. Cutover 전에 사용자 샘플·회귀테스트·독립 복구 도구를 준비합니다.

## 경계

- 구버전과 신버전에서 같은 데이터를 동시에 수정하지 않도록 ownership을 단일화합니다.
- v1→v2 변환은 비파괴 복사본에서 수행합니다.
- 단계별 UI 기능 플래그는 영속 포맷/커널 변경의 안전장치를 대체하지 않습니다.
