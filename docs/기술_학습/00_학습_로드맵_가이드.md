## 학습 원칙

단순 개념 나열이 아니라 **문제 → 원리 → CAD Studio 적용 → 재현 실습 → 실패 사례 → 결과 측정** 순서로 공부합니다.

## 학습 단계

1. Rust 타입/CS/동시성 + 기하학·선형대수 기초
2. Sketch Solver와 2D 정밀도/좌표계
3. B-Rep·C++ 커널/FFI·피처 의존성 그래프
4. wgpu·렌더링·Picking·캐시/정밀도
5. 저장·마이그레이션·외부 CAD 교환·DevSecOps
6. 제조 도면, 치수·공차, 건축 확장에 필요한 도메인 검증

## 숙달 판정

각 주제를 설명할 수 있을 뿐만 아니라 작은 fixture를 작성하고, 실패 케이스와 오류 진단 코드를 제시할 수 있어야 합니다.
